# Sample guides

Each folder here is a finished guide (guide.json, highlighted keyframes, video). The app copies
them into `data/guides/` on start, so a fresh clone opens to a guide ready to coach, even in
demo mode without an API key.

Only our own footage goes here. Ego-Exo4D clips must never be committed (license).
Add one with: `python scripts/export_demo.py <guide_id>`
